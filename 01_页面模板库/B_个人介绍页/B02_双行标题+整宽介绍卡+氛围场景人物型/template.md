# 1. Layout Overview

整体采用「顶部双行 About Me / 关于我 标题 + 整宽人物介绍卡 + 中下婚礼氛围场景底图 + 右下人物主体 + 左下双数据卡」。

阅读顺序：About Me / 关于我 → 整宽人物介绍卡 → 右下人物主体与婚礼氛围 → 核心数据。

核心结构不可改变：

- 顶部标题固定为两行客户提供文案：第一行「About Me」为大号主标题，第二行「关于我」为较小副标题；不在此区域放客户姓名。
- 介绍卡接近页面全宽；卡内左侧为真实人物抠图，右侧为 title 与介绍文字。
- 卡片左人物的头部和肩部越过卡片上缘，形成浮于卡片前方的层次。
- 中下区域为无可识别人物面部特写的婚礼主持氛围场景，向右、向下延展，作为右下人物主体的底层。
- 右下为客户真实人物主体，左下两张数据卡纵向叠放。

## Area 01 — 顶部标题区

只放客户 `copy.md` 提供的两行标题：第一行「About Me」为大号主标题，第二行「关于我」为较小副标题。两行右侧对齐，不放姓名、拼音姓名、英文名或职业身份。可在标题附近加入低权重、无事实含义的字母装饰，但不得替代标题。

## Area 02 — 整宽介绍卡与人物抠图

卡片横跨内容区，作为页面第一信息容器。卡片左侧使用客户真实照片抠图；人物需从卡片上缘突破，头部和肩部露在卡片之外，且不遮挡顶部双行标题。卡片右侧承载客户提供的职业 title 与真实介绍文案。卡片的圆角、边框、玻璃感和材质由风格决定。

## Area 03 — 婚礼氛围场景底图区

用于传递婚礼主持职业氛围，而非展示可识别客户。允许使用无清晰人脸的仪式空间、舞台光束、花艺、观众背影或远景剪影；不得出现可识别的人物脸部、虚构的客户主持人、具体项目名称、品牌或案例信息。该场景从中部左侧开始，向右、向下延展，并置于右下人物主体底层。

## Area 04 — 右下人物主体区

使用客户真实照片抠图，人物主体从中部向底部延展，覆盖在婚礼氛围场景底图上。脸部和上半身须清晰，文字不得覆盖五官。人物服装、体态、年龄和身份不得改变。

## Area 05 / 06 — 纵向双数据卡

上卡对应真实主持场次，下卡对应真实从业年限。每卡为「大号数值 + 单位 + 指标名称」；两卡同宽、纵向等距排列。数值必须由客户提供，缺失时保留卡片与文字区域空白。

# 3. Character Rules

- 卡片左人物与右下人物主体均使用同一客户的真实素材。
- 优先使用两张真实照片：一张用于介绍卡左侧抠图，一张用于右下主体；素材不足时可对同一真实照片做不同裁切复用。
- 只允许抠图、裁切、背景融合、光影优化与色彩调整。
- 不允许改脸、改发型、改年龄、改身材比例、改服装职业属性或补全不存在的肢体与配饰。
- 婚礼氛围场景不得生成可识别的新人物或可被理解为客户真实履历的案例。

# 4. Background and Layering Rules

- 风格由指定 `style.md` 决定；B02 只控制结构，不绑定预览中的手绘黑白效果。
- 层级从后至前依次为：背景 → 婚礼氛围场景底图 → 整宽介绍卡与数据卡 → 卡片左人物抠图、右下人物主体 → 标题与文字。
- 人物、场景与介绍卡形成层次，但不能互相遮挡核心标题、介绍文字和数据卡。
- 装饰仅可围绕既有标题、卡片边缘、背景线条或留白区域弱化使用，不增加第三张数据卡、服务清单、荣誉墙、标签组或二维码。

# 5. Information Hierarchy

1. About Me / 关于我 与整宽介绍卡中的人物及 title。
2. 右下人物主体。
3. 婚礼氛围场景与纵向双数据卡。
4. 弱装饰与背景元素。

# 6. Alignment Rules

- About Me / 关于我双行标题与介绍卡右文案沿右列对齐。
- 整宽介绍卡左右边界与婚礼氛围场景的安全边界对齐。
- 左下两张数据卡的左边、右边和内部文字基线一致。
- 右下人物主体可突破婚礼氛围场景边缘，但不得越过页面安全边距。
- 卡片左人物与右下主体保持足够分离，不遮挡彼此的脸部或卡片核心文字。

# 7. Style Replacement Rules

允许替换：客户真实照片、客户提供的 title、身份、数据、定位与特点文案，以及指定风格下的色彩、字体、材质、光影和弱装饰。

不允许替换：顶部双行 About Me / 关于我、整宽介绍卡内的左人物右文案、婚礼氛围场景位于右下主体底层、左下纵向双数据卡、画布比例、阅读顺序与底部留白。

# 8. Generation Constraints

- 成品画布为 1088 × 2176 px，比例 1:2。
- 个人介绍页必须调用 Workflow_B，并校验 B02、指定风格、客户资料和真实照片。
- 核心标题、姓名、身份、经历、数据、定位与特点文案必须来自客户资料；无事实含义的低权重英文或字母排版可作为弱装饰。
- 禁止生成客户拼音姓名、虚构经历、机构、场次、年限、宣传语与人物。
- 禁止 AI 生成替代客户照片。
- 禁止生成手机框、状态栏、图外批注、指示箭头、尺寸标注或结构说明文字。
- 不新增未定义信息模块；缺失数据保留空白。

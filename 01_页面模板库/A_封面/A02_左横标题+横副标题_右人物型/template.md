# A02\_左横标题+横副标题\_右人物型

## Template ID

A02


## Template Name

左横标题+横副标题_右人物型


## Template Category

封面人物展示模板


## Canvas

尺寸：

1088 × 2176 px

比例：

1:2 竖版

---

# 1. Layout Overview

整体采用：

「左侧文字信息区 + 右侧人物主体区 + 底部延展留白区」

左右分栏视觉结构。


页面视觉重点：

左侧：

主标题
↓
英文签名/辅助信息
↓
身份副标题
↓
品牌标语

右侧：

人物主体

底部：

背景延展空间

核心结构不可改变：

- 左侧负责品牌信息表达
- 右侧负责人物视觉展示
- 主标题与副标题均采用横向排列
- 人物保持右侧主体位置


---

# 2. Layout Structure


页面主要分为五个区域：


## Area 01

顶部辅助信息区


位置：

页面顶部左右两侧。


占比：

约5%-8%。


内容：

可放置：

- 英文小标题
- 品牌英文
- 装饰文字
- 简短辅助信息


要求：

信息弱化处理。


禁止：

- 大面积占用顶部空间
- 抢夺主标题视觉


---

## Area 02

左侧主标题区域


位置：

左侧中上区域。


宽度：

约25%-35%。


高度：

约12%-18%。


排列方式：

横向排列。


内容：

姓名
品牌名称
主题标题

示例：

欣仪

视觉等级：

最高。


要求：

- 字号最大
- 强视觉识别
- 保持左侧独立空间


禁止：

× 改为竖排标题

× 放置到顶部中央

× 与人物重叠

---

## Area 03

英文签名 / 拼写区域


位置：

主标题下方。


用途：

补充人物品牌感。


内容：

例如：

Xinyi

English Name

要求：

- 小字号
- 装饰性强
- 不影响主标题


可根据风格：

替换为：

- 英文名
- 手写签名
- 品牌短句


---

## Area 04

横向副标题区域


位置：

左侧中部。


排列：

横向排列。


内容：

人物身份说明。


示例：

婚礼主持人

WEDDING HOST

视觉等级：

低于主标题。


要求：

作为人物职业补充。

---

## Area 05

标语文案区域


位置：

左侧中下区域。


内容：

品牌理念 / 服务价值。


示例：

让表达有温度
让仪式有回响

文字长度：

10-30字。


排版：

支持：

- 两行
- 三行


要求：

保持高级感和呼吸感。

## 版面约束补充
- 左侧中下部区域不放置任何额外文字块、标签组、业务分类列表或说明性小模块。
- 该区域保持留白，用于增强画面呼吸感。
- 页面文字信息仅保留：主标题、英文签名（如需要）、横向副标题、标语文案、必要的顶部辅助信息。
- 禁止在人物左下侧新增小型信息框、分类框、列表框

---

# 3. Character Area


## Position

页面右侧。


## Size

宽度：

约50%-60%。


高度：

约60%-70%。


## Character Type

适合：

- 半身人物
- 3/4身人物
- 全身人物


人物视觉：

作为页面第二核心。

---

# 4. Character Placement Rules


人物必须：


✓ 位于右侧

✓ 保持完整轮廓

✓ 人物头部位于右上区域

✓ 身体向下延展


人物与文字关系：

左侧文字区域

​    ↓

保持视觉分离

​    ↓

右侧人物区域

禁止：

× 人物移动到左侧

× 人物遮挡标题

× 文字覆盖脸部

× 人物过度放大导致文字空间不足

---

# 5. Foreground Decoration Area


## Position

页面底部及左右边缘。


用途：

增加空间层次。


可使用：

- 光带
- 花瓣
- 曲线
- 装饰纹理
- 氛围元素


要求：

装饰服务于：

人物 + 文字。


禁止：

- 影响阅读
- 覆盖人物主体


---

# 6. Bottom Extension Area


## Position

页面底部。


高度：

约10%-14%。


用途：

- 背景延续
- 长图拼接
- 氛围过渡


要求：

保持干净。


禁止：

放置核心信息。

---

# 7. Background Rules


背景根据主题自由变化。


支持：

- 婚礼高级感
- 商务品牌
- 黑金奢华
- 清透自然
- 艺术杂志风


背景元素：

允许：

- 渐变
- 光影
- 空间纹理
- 柔性线条
- 装饰元素


要求：

突出人物和标题。


禁止：

背景复杂导致文字不可读。

---

# 8. Information Hierarchy


固定层级：

一级：

人物姓名 / 主标题

二级：

人物主体

三级：

身份副标题

四级：

品牌标语

五级：

辅助装饰信息

---

# 9. Alignment Rules


左侧文字：

默认：

左对齐。


主标题：

横向排列。


副标题：

横向排列。


标语：

左对齐。


人物：

右侧视觉中心。

---

# 10. Style Replacement Rules


该模板控制：

「结构布局」


允许替换：

- 人物
- 背景
- 色彩
- 材质
- 光影
- 装饰元素


不允许替换：

- 左文字右人物结构
- 主标题位置
- 副标题位置
- 人物位置
- 页面比例


---

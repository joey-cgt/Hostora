# A03\_左竖标题+横副标题\_右人物型

## Template ID

A03


## Template Name

左竖标题 + 横副标题 + 右人物型


## Template Category

封面人物展示模板


## Canvas

尺寸：

1080 × 2160 px

比例：

9:16 竖版

---

# 1. Layout Overview

整体采用：

「左侧文字信息区 + 右侧人物主体区」双栏结构。


页面视觉关系：

```
左侧信息
    +
右侧人物

形成左右平衡的人物品牌封面。
```


核心结构不可改变：

- 标题固定左侧
- 人物固定右侧
- 文字不进入人物主体区域
- 保持明显左右分区


---

# 2. Layout Structure


## Left Information Area

位置：

页面左侧。


宽度：

约占整体宽度 25%-35%。


包含：

1. 主标题区域
2. 副标题区域
3. 标语理念区域
4. 辅助信息区域


排列顺序：

```
竖向主标题

↓

横向副标题

↓

品牌理念/标语

↓

辅助文字
```

---

# 3. Main Title Area


## Position

左侧上方。


## Layout

竖向排列。


## Content

主要展示：

- 人物姓名
- 品牌名称
- IP名称


示例：

```
林
若
溪
```


## Text Rules

字符数量：

2-4个中文字符。


字体：

推荐：

- 高级衬线字体
- 品牌感字体
- 书法字体


视觉权重：

页面最大文字元素。


禁止：

- 横向排列
- 多行长标题
- 大段文字


---

# 4. Subtitle Area


## Position

主标题下方。


## Layout

横向排列。


## Content

人物身份信息。


示例：

```
婚礼主持人

WEDDING HOST
```


文字长度：

8-12字。


视觉等级：

低于主标题。

---

# 5. Slogan Area


## Position

副标题下方。


## Content

品牌理念、服务价值。


示例：

```
以声音传递温度
以仪式珍藏幸福
```


文字长度：

10-20字。


排版：

支持：

- 两行排列
- 左对齐
- 居中排列


---

# 6. Auxiliary Information Area


## Position

左侧中下区域。


内容：

可放：

- 英文辅助文字
- 服务关键词
- 品牌描述
- 装饰文字


要求：

保持低视觉权重。


禁止：

占据主要视觉区域。

---

# 7. Character Area


## Position

页面右侧。


## Width

约占页面：

50%-60%。


## Height

约占页面：

60%-70%。


## Character Type

适合：

- 人物肖像
- 职业形象照
- 半身人物
- 3/4身人物


人物姿态：

推荐：

- 正面站姿
- 微侧身
- 自然职业姿态


---

# 8. Character Placement Rules


人物必须：

- 位于右侧
- 保持完整轮廓
- 头部位于中上区域
- 身体向下延展


人物与文字关系：

```
文字区域 ≠ 人物区域

两者保持空间分离。
```


禁止：

- 人物移动到左侧
- 人脸被文字覆盖
- 标题覆盖人物脸部
- 人物遮挡主要文字


---

# 9. Background Rules


背景根据主题变化。


支持：

- 婚礼高级感
- 商务风
- 黑金风
- 清透风
- 艺术杂志风


背景元素：

允许：

- 光线
- 柔性曲线
- 几何纹理
- 渐变
- 空间层次


要求：

背景服务于：

人物 + 文字。


禁止：

- 高对比背景影响文字阅读
- 复杂元素破坏结构


---

# 10. Bottom Extension Area


位置：

页面底部。


高度：

约10%-15%。


用途：

- 背景延展
- 装饰元素
- 下一页面连接


禁止：

放置核心信息。

---

# 11. Information Hierarchy


固定视觉层级：


```
一级：

人物姓名 / 主标题


二级：

人物主体


三级：

身份副标题


四级：

品牌理念


五级：

辅助文字
```

---

# 12. Generation Constraints


AI生成必须保持：


布局：

✓ 左侧竖标题  
✓ 左侧横副标题  
✓ 右侧人物主体  
✓ 底部保留延展空间  


比例：

✓ 1080×2160竖版  
✓ 左右分栏结构  


禁止修改：

× 不改变标题方向  
× 不改变人物位置  
× 不改变左右布局  
× 不增加复杂信息模块  

---

# 13. Style Replacement Rules


该模板只控制：

「结构」


允许替换：

- 背景颜色
- 材质风格
- 光影效果
- 人物服装
- 装饰元素


不允许替换：

- 页面结构
- 标题位置
- 人物位置
- 信息层级


---

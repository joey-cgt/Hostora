# A01_顶部标题人物居中型

## Template ID

A01


## Template Name

顶部标题人物居中型


## Template Category

封面人物展示模板


## Canvas

尺寸：

1088 × 2176 px

比例：

1:2 竖版

---

# 1. Layout Overview

整体采用：

「顶部标题信息区 + 中部人物主体区 + 底部过渡留白区」

单中心视觉结构。

页面视觉重点：

顶部标题

↓

副标题

↓

品牌标语

↓

人物主体

↓

底部延展空间





核心结构不可改变：

- 标题位于页面顶部中央
- 人物主体位于页面中心区域
- 所有文字保持居中对齐
- 人物作为主要视觉主体


---

# 2. Overall Layout Structure


页面分为五个核心区域：


## Area 01

顶部标题区


位置：

页面顶部。


占比：

约12%-16%高度。


内容：

- 姓名
- 品牌名称
- 主视觉标题


排列：

水平居中。


视觉等级：

最高。


要求：

标题必须具有品牌识别度。


禁止：

- 标题靠边
- 标题进入人物区域
- 使用过长标题


---

## Area 02

副标题区域


位置：

主标题下方。


占比：

约8%-12%高度。


内容：

人物身份信息。

示例：

婚礼主持人

WEDDING HOST



排列：

水平居中。


视觉等级：

低于主标题。


要求：

作为身份补充说明。

---

## Area 03

标语区域


位置：

副标题下方。


占比：

约8%-10%高度。


内容：

品牌理念、服务价值。

示例：

言有温度

礼有分寸



文字长度：

10-20字。


排版：

支持：

- 一行
- 两行


要求：

保持高级、简洁、有情绪。

---

# 3. Character Area


## Position

页面中心偏下区域。


## Size

高度：

约45%-55%。


宽度：

约50%-70%。


## Character Type

适合：

- 人物肖像
- 半身人物
- 3/4身人物


人物位置：

页面中心。


人物姿态：

推荐：

- 正面站姿
- 自然职业姿态
- 双手自然摆放


---

# 4. Character Placement Rules


人物必须：

✓ 位于中心区域

✓ 保持完整人物轮廓

✓ 头部位于人物区域上方

✓ 身体向下延展

人物与文字关系：

标题区域

↓

人物区域

保持上下空间关系



禁止：

× 人物遮挡标题

× 文字覆盖脸部

× 人物偏移左右

× 人物过大导致顶部文字空间不足

---

# 5. Bottom Extension Area


## Position

页面底部。


## Height

约10%-14%。


用途：

- 背景延续
- 装饰元素
- 下一张长图衔接


要求：

保持干净留白。


禁止：

- 放置主要信息
- 增加复杂元素


---

# 6. Background Rules


背景根据主题变化。


支持风格：

- 婚礼高级感
- 商务品牌
- 黑金奢华
- 清透自然
- 艺术杂志


背景元素：

允许：

- 光效
- 渐变
- 柔性曲线
- 空间纹理
- 装饰线条


要求：

背景服务于：

人物 + 标题。


禁止：

- 背景抢夺标题视觉
- 复杂纹理影响文字阅读


---

# 7. Information Hierarchy

固定视觉层级：

一级：

人物姓名 / 主标题

二级：

人物主体

三级：

身份副标题

四级：

品牌标语

五级：

辅助装饰信息



---

# 8. Alignment Rules


所有文字：

默认：

居中对齐。


标题：

必须水平居中。


副标题：

必须水平居中。


标语：

必须水平居中。


人物：

中心对齐。

---

# 9. Style Replacement Rules


该模板只控制：

「页面结构」


允许替换：

- 人物
- 背景
- 色彩
- 材质
- 光影
- 装饰元素


不允许替换：

- 标题位置
- 人物位置
- 信息层级
- 页面比例


---

# 10. Generation Constraints


AI生成必须保持：


布局：

✓ 顶部标题

✓ 中部人物

✓ 居中排版

✓ 底部留白


比例：

✓ 1088×2176

✓ 1:2竖版


禁止：

× 左右分栏

× 人物移动到侧边

× 标题放在底部

× 改变视觉中心

---

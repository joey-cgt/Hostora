# 主持人IP视觉系统 Workflow


# 01_Workflow系统说明


## 系统定位


Workflow用于管理主持人IP视觉系统中的不同设计生产流程。


Workflow负责：

- 定义任务执行步骤
- 指定读取文件
- 控制生成流程
- 定义输出规则


Workflow不负责：

- 定义视觉风格
- 定义页面模板
- 存储客户资料


---

# 02_Workflow调用规则


用户输入任务后：AGENTS.md负责解析命令，根据任务类型调用对应Workflow。

例如：

- 生成主持人封面调用：Workflow_A
- 生成个人介绍页:调用Workflow_B

---

读取：

profile.md

---

## A-04 生成规则


必须：

- 按下文「整页一次生成执行规则」直接生成完整主持人封面

- AI生成替代人物

# 03_整页一次生成执行规则

本规则适用于 Workflow_A 和 Workflow_B 的每个新候选版本。

1. 完成参数校验和 A-03 / B-03 文件读取后，选用客户提供且适合当前模板的原始 portrait 照片。将模板结构图、风格参考图、客户原始照片作为同一次图像生成请求的图像输入；将 `template.md`、`style.md`、`profile.md` 和 `copy.md` 的约束及准确文案写入同一个完整页面提示词。不得使用旧候选图或旧抠图替代客户原始照片。
2. 在一次请求中直接生成包含真实人物、指定背景、准确文案和完整排版的整页结果图。A 页面输出完整封面，B 页面输出完整个人介绍页；不得先请求背景、人物抠图、局部文字或其他组件，也不得用 Pillow、SVG、HTML/CSS、画布脚本等方式自行拼接页面。
3. 每次请求产出的完整图都先保存为新版本的 `image.png`，在 `prompt.md` 记录原始输入路径、完整提示词、生成工具和实际输出尺寸，再检查客户身份与五官、人物完整轮廓、文字准确性、模板位置、风格一致性、页面尺寸和视觉完成度。新版本只需保存整图和记录，不为该流程生成背景图、抠图或合成脚本。
4. 若检查未通过，在该版本的 `feedback.md` 记录问题，从客户原始文件和模板/风格参考重新发起完整页面生成，按迭代规则保存为下一版本。若工具无法在整页一次生成方式下满足人物真实性或页面要求，停止交付并说明限制，不切换为分层合成。

## feedback.md生成与更新流程

feedback.md用于记录：AI生成版本在迭代过程中的问题分析和优化方向。

它属于：05_迭代过程库。

用于连接：当前版本→问题分析→下一版本优化。



不是每一次生成都需要。

推荐规则：

V001 首次生成时，生成：

V001

├── image.png
└── prompt.md

如果用户没有反馈：

不用生成 feedback.md。



以下情况需要生成feedback.md：

用户提出修改需求。例如：

- 修改一下
- 优化一下
- 重新生成
- 换一种感觉
- 不够高级
- 人物需要调整
- 风格需要调整

执行：创建当前版本对应的feedback.md。

例如：

V001

├── image.png
├── prompt.md
└── feedback.md

然后生成V002，例如：


├── V001

│   ├── image.png
│   ├── prompt.md
│   └── feedback.md


└── V002

├── image.png
└── prompt.md

如果V002继续修改，增加V002/feedback.md，不要修改V001/feedback.md



feedback.md记录内容：

```
# 当前版本信息
记录：

- 客户名称
- Workflow类型
- 页面模板
- 视觉风格
- 当前版本号

# 当前版本问题
分析：

- 页面结构问题
- 视觉风格问题
- 人物表现问题
- 文案问题
- AI生成问题

# 用户反馈
记录:用户明确提出的修改要求。

# 修改方向
定义下一版本调整方向。包括：
- 页面调整
- 人物调整
- 风格调整
- 文案调整

# 下一版本目标
明确：下一版本需要达到的效果。

```



## 最终确认流程

用户确认：

- 可以
- 定稿
- 最终版

执行：选择最佳版本，将最终结果复制到04_输出案例库，保存final.png、config.md、review.md

停止继续生成feedback.md。



目录结构：

客户名称/Workflow_B_个人介绍页/Bxx_Sxx

示例：

04_输出案例库

└── 张三

└── Workflow_B_个人介绍页

​    └── B01_S08

​        ├── final.png
        ├── config.md
        └── review.md

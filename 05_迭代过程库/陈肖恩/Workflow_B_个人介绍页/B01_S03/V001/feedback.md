# 当前版本问题

- 左侧辅助照片模块已不符合当前页面需求。
- 个人定位位于人物主体上方，未形成位于人物左侧、特点文案上方的左侧文本列。
- 数据卡片与身份介绍区的空间分配不符合新版固定坐标。

# 用户反馈

- 删除辅助照片区。
- 定位置于人物主图左侧、主持特点文案上方，并与特点文案使用不同字体层级。
- 主持特点文案固定于更低的左侧区域。
- 双数据卡片固定在 Y 轴 34%–47%。
- 身份介绍区固定在 Y 轴 18%–30%。

# 修改方向

- 应用 B01 单人物模板：仅保留一个右侧人物主体。
- 按新模板固定坐标重新排布所有模块。
- 定位与特点文案均直接置于背景，且不使用外框。
